ProductProviderRegistry

class ProductProviderRegistry

Registry of ProductProvider impls supplied by provider plugins.

Providers self-register via META-INF/services/…ProductProvider — loaded automatically at construction with the SPI class's own classloader (not the TCCL — transforms/workers isolate it) — and may additionally call register programmatically.
