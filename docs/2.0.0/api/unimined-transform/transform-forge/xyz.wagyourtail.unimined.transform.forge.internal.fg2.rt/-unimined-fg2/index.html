UniminedFg2

class UniminedFg2

Runtime helpers injected into FG2-era dev environments (1.x's `unimined$*` methods, previously emitted as raw ASM bodies inside forge classes — now compiled Java spliced into the dev jar by the `forge-fg2-fixes` step and referenced via INVOKESTATIC).

Everything here is classpath/resource shim logic for making FG2-era FML behave like the modern dev classpath: resources and language files found through MOD_CLASSES, coremods discovered on java.class.path.
