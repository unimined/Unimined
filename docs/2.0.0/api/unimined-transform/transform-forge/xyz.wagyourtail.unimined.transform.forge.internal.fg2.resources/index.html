transform-forge/xyz.wagyourtail.unimined.transform.forge.internal.fg2.resources

Package-level declarations

MOD_CLASSES resource lookup for FG2-era FML (PROP_MOD_CLASSES).

In dev, FML sets MOD_CLASSES to dir1;dir2 per mod — the mod's classes/ + resources/ output dirs — because there is no jar to read. FG2-era classes only partially honor this: FMLFolderResourcePack reads resources from the dirs but doesn't report them in its domain/has checks, LanguageRegistry only scans the jar file, and DirectoryDiscoverer never finds mcmod.info on a classpath dir. These transformers close those gaps.

Disable at runtime with -Dunimined.fg2.modClasses=false.
