LoaderApiProvider

interface LoaderApiProvider

A loader "api" artifact provider — the 2.0 port of 1.x's FabricLikeApiExtension, keyed by name instead of a method per loader. Resolves the aggregate api module (full) or individual sub-modules (module) by reading the api artifact's pom (and, for Ornithe, its meta endpoint).
