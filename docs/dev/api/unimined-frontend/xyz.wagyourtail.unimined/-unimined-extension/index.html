UniminedExtension

abstract class UniminedExtension @Inject constructor(project: Project)

The unimined { } facade — an aggregator presenting one DSL that fans out to the underlying plugins' extensions. Each underlying plugin remains independently applicable; this only folds them into one interface. Transform-agnostic: transforms declare themselves through the transform builder API on TransformExtension.
