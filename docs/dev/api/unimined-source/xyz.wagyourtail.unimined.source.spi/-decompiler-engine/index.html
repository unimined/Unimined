DecompilerEngine

interface DecompilerEngine : Supports<DecompileSpec>

SPI implemented by each unimined-decompiler-* plugin (vineflower default; fernflower, cfr, others as needed) — same host+SPI selection model as remappers and providers.

Implementations are discovered via ServiceLoader — META-INF/services/xyz.wagyourtail.unimined.source.spi.DecompilerEngine.
