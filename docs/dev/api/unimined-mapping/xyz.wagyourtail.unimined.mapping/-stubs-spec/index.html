StubsSpec

open class StubsSpec(namespaces: List<String>) : MappingTreeDsl

The stubs { } block scope — inline patch rows layered onto the environment's composed mappings (1.x stubs(*namespaces) { }).

Cell values are positional across the namespaces declared on the stubs(...) call; a null cell leaves that namespace unmapped. c/f/m are the 1.x verb names; clazz/field/method (and the rest of MappingTreeDsl's surface — pkg, parameter, wildcard, tweaker directives) work too.

mappings {
    stubs("official", "named") {
        c("a/b", "com/example/Foo") {
            m("c;()V", "run")
        }
    }
}
