fun env(env: String, srcNs: String = "official")

Tag this source's jar-side namespace srcNs as belonging to environment env — its rows land in the srcNs:env column (envView(E) = ns ∪ ns:env). For env-free formats (Ornithe gen-1 -client/-server artifacts, split SRG files) this is the file-level default; formats carrying per-row env (MCP v6) tag rows themselves. srcNs is the source's jar-native (obf) column — official by default.
