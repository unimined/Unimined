LegacyDistArtifactProducer

class LegacyDistArtifactProducer : ProductArtifactProducer

Execution-time counterpart to LegacyDistProvider: materializes the declared-source artifact inside the raw-artifact transform — local file/url sources into the shared native-cache, producer() sources via a ProcessBuilder runner (BuildToolsArtifactProducer proved a subprocess works in transform isolation; the descriptor-keyed cache is the same "declared inputs are the contract" model BuildTools' opaque output already carries).

supports is the declared-source floor: it claims every spec carrying a declaredSource at a priority below devbundle's format-marker claim (5) so tagged declared sources still reach their specialized producer, and above native's catch-all (0) so a plain declared jar never falls through to the vanilla pipeline.
