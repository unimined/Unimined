DistSpec

class DistSpec

Configuration surface for the dist preset verbs (MinecraftEnvironment.bta/MinecraftEnvironment.reindev/ MinecraftEnvironment.nsss/MinecraftEnvironment.custom).

Exposes the environment's product/version/side/loader config plus the declared-source verbs (file/maven/url/producer) for dists with no upstream index. Declared sources are routed through LegacyDistSpec directly — unlike MinecraftEnvironment.legacydist they do NOT force provider("legacydist"), so conversion-family envs keep their conversion provider claim while still accepting a user-declared jar (e.g. nsss, or a custom conversion dist).
