Lwjgl3Spec

abstract class Lwjgl3Spec @Inject constructor(objects: ObjectFactory)

The env-level lwjgl3 { } spec — RetroFuturaGradle's lwjgl3 bindings-swap parity: drop the version-JSON's org.lwjgl.lwjgl:* (lwjgl2 core/util/platform and its natives entries) and put lwjgl3 artifacts on the environment's classpath + natives set instead, for running old Minecraft on modern JVMs. The lwjgl3ify mod itself is a user dependency — this surface only swaps the bindings, mirroring RFG's model (its lwjgl3Configuration + lwjgl3Bindings props).
