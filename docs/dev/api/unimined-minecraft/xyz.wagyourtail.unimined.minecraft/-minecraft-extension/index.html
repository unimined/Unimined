MinecraftExtension

abstract class MinecraftExtension @Inject constructor(project: Project, val objects: ObjectFactory, providers: ProviderFactory, exec: ExecOperations, dependencyFactory: DependencyFactory)

The minecraft { } DSL: owns an independent environment per source set. The legacy flat properties are aliases for main, while sourceSet configures additional environments.

minecraft {
    version = "1.20.1"      // convenience for version.set(...)
    side.set(Side.MERGED)   // default MERGED
    loader("forge", "47.2.0")
    provider.set("mavenizer") // optional DSL override
}
