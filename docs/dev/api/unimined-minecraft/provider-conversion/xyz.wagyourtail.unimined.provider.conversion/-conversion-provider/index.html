ConversionProvider

class ConversionProvider : ProductProvider

Total-conversion provider — provider("conversion"). The dist jar IS the complete Minecraft jar (reindev / bta / nsss): no vanilla manifest, no remap — prodNamespace is official throughout and the env rides the identity namespace path.

Claims specs whose loader is a conversion product. Sided dists resolve client+server jars separately; a MERGED env fetches both and rides the standard client/server merge machinery.

Artifact + launch sources per product:

  • reindev: cdn.fox2code.com/files/reindev-{client,server}-{ver}.jar (2.8.1_5+) or reindev-{ver}-{client,server}.jar (≤2.4.x) — both patterns tried; launch doc is Mojang's b1.7.3 version JSON (1.x baseVersion)

  • bta: downloads.betterthanadventure.net/bta-{client,server}/ release/v{ver}/ — the per-version manifest.json IS a complete Mojang-schema version document (libraries, sided downloads with sha1, assetIndex, mainClass)

  • nsss: declared file/URL source only (no upstream index); launch doc rides the base version like reindev
