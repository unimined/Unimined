DevBundleExportSpec

abstract class DevBundleExportSpec

Per-environment dev-bundle export settings, contributed by the xyz.wagyourtail.unimined.provider.devbundle plugin as the devBundleExport extension on every MinecraftEnvironment — sourceSet("main") { devBundleExport { serverJar.set(...) } }.

Pure configuration — nothing runs unless the export<Env>DevBundle task is invoked (the task is the opt-in; there is no enabled flag). Defaults make a plain devBundleExport {} usable: the env's production artifact, version, and library/repo lists all convention onto the environment.

The produced zip is a paperweight dev bundle (data version 6): data/paperclip-mojang.jar carries the prod jar embedded inside a self-contained reproducer — consumers running it get the exact artifact back (no binary patching involved), and unimined's devbundle { file(...) } provider path reads it directly.
