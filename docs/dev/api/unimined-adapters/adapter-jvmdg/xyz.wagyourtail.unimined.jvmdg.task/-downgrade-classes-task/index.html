DowngradeClassesTask

@DisableCachingByDefault(because = "jvmdg engine output isn't relocation-verified; up-to-date checks cover the rerun cost")
abstract class DowngradeClassesTask : DefaultTask, ShadeFlags

Downgrades every directory in inputDirs to ShadeFlags.downgradeTo via JvmDowngrader, mirroring each input dir to outputDir/<index> so classpath order is preserved. Registered per-environment by the unimined-jvmdg compat plugin when the env's jvmdowngrader extension is enabled — old-loader runtimes (FG-era LaunchWrapper/FML ship ASM 4/5.2 and cannot read >v52 classes) launch against the downgraded dirs instead of the raw compile outputs.

The task implements jvmdg's Gradle-frontend ShadeFlags — its property inputs carry the interface's @Input annotations and are conventioned wholesale from the env's JvmDgEnvSpec (see convention(spec) in JvmdgEnvWiring), so every engine knob the user sets on jvmdowngrader { } reaches toFlags at execution.
