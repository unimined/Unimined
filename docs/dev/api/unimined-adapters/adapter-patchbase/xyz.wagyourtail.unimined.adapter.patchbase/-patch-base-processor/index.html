PatchBaseProcessor

class PatchBaseProcessor : JarProcessor

Applies PatchBase patch jars (patchBase<env> configuration) to the environment's MC jar — the 2.0 counterpart of 1.x's MinecraftConfig.patchBase/customPatcher. Runs pre-remap: cdiff patches target prod-namespace classes (same constraint as jarmod:merge).

The env wiring resolves patch jars via envArtifacts("patchbase") at spec-build; the spec carries path:sha entries so the cache key tracks content and processJar can reopen them.
