PatchBaseCreatorSpec

abstract class PatchBaseCreatorSpec

Knobs for patchBaseCreator — the mache/git-style text-patch loop layout. Defaults follow the reference workflow: the git-tracked unified-diff set in patches/ (per-env patches/<env> when not main) and the generated, edit-in-place patched sources in src/<env>/java.

applySourcePatch regenerates the whole sourceDir tree from patchDir on every run — a patchbase project keeps ONLY patch-materialized files there; mix in hand-written sources and they are deleted on the next apply. Point sourceDir at a dedicated tree (or use a dedicated env) when the project also carries normal sources.
