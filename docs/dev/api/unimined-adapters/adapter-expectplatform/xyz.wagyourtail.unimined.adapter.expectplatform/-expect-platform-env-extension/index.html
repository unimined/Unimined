ExpectPlatformEnvExtension

abstract class ExpectPlatformEnvExtension(project: Project, env: MinecraftEnvironment)

Per-env expectPlatform DSL object — registered on each environment by the adapter plugin when ExpectPlatform's plugin is applied.

platform is the per-env opt-in for ExpectPlatform dependency transforms; it also seeds platformName so the agent + JAR wiring activate for this env. enabled/agent are the opt-outs: a child env that inherits platformName can exempt itself with enabled.set(false), and agent.set(false) drops the javaagent from dev runs while keeping the static jar transform.
