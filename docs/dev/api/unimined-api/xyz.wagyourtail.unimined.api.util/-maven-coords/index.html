MavenCoords

@JvmInline
value class MavenCoords(val value: String)

group:artifact:version[:classifier][@extension] coordinate string — the identifier loaders use when selecting embedded (jar-in-jar) candidates. The loaders' matching semantics live in ResolvedArtifactResult.getCoords: it constructs these from the variant's component id, resolved capabilities, and file-name classifier detection — the same inputs forge/fabric first-party tooling reads, so embedded ids line up. The getters here parse the string form (Gradle g:a:v:c@e notation) for DSL-facing uses like include("g:a:v") lookups.
