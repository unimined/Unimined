UniminedTools

abstract class UniminedTools @Inject constructor(objects: ObjectFactory)

Detached-tool coordinate registry — uniminedTools { }.

Every hardcoded tool coordinate Unimined resolves into a detached configuration is surfaced here as a Property<String> holding the full g:a:v[:classifier][@ext] notation, so users can override the version (or fork) without forking the plugin:

uniminedTools {
    jst.set("net.neoforged.jst:jst-cli:2.1.0")
}
Content copied to clipboard

Registered lazily via Project.uniminedTools — any plugin module can look it up without apply-order coupling. Properties carry conventions, so reading them never triggers resolution.
