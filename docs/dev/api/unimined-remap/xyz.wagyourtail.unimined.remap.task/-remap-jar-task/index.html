RemapJarTask

@CacheableTask
abstract class RemapJarTask : Jar, ProducesArtifacts

Builds the production artifact directly: the task is a Jar whose spec mirrors the development jar's (rootSpec.with(jar.rootSpec) + manifest.from(jar.manifest) — wired by the registration site), so it depends on the jar's inputs (classes, resources) rather than on the jar task's output the way 1.x remapJar did.

copy assembles the mirrored contents to a scratch jar, then runs the declared RemapSurface.JAR step pipeline dev→prod over it into archiveFile.
