abstract class RemapArtifactTask : AbstractRemapTask, ProducesArtifacts

Remaps an arbitrary artifact between namespaces by running a declared xyz.wagyourtail.unimined.remap.spi.RemapSurface step pipeline over inputArtifact into outputArtifact — the generic input→output sibling of RemapJarTask (which assembles its own jar from a mirrored CopySpec instead). Used for surfaces whose input is produced by another task — the decompile fork, the sources-surface remap of a generated sources jar.
