RemappedViewSet

class RemappedViewSet : FileCollection

Result of RemapExtension.remappedViews or RemapExtension.remappedViewsFor.

views exposes the generated namespace-specific resolvable configurations; the object itself is a FileCollection containing all of them, so it can be passed directly to classpath.from(...), a task input, or another file collection.
