RemapExtension

abstract class RemapExtension @Inject constructor(project: Project, val objects: ObjectFactory, providers: ProviderFactory)

The remap { } DSL: ordered step pipelines per RemapSurface, plus remapped views over dependency configurations.

remap {
    jar {
        remap("tiny")          // the namespace-changing step
        unpick(unpickDefs)     // e.g. a UML step, post-remap
    }
    sources {
        remap("uml")
    }
}

fun pipelineSteps(environmentId: String, surface: RemapSurface): Provider<List<StepSpec>>

The executable pipeline for a surface: transform-contributed pre steps (original-namespace input — loader binary patching), the declared (or inherited) steps or an implicit remap core when a JAR surface was left unconfigured, then post steps. Hosts feeding unimined-managed artifacts (dev jars, environment mod buckets) use this so empty pipelines still namespace-remap.
