RemappedViewsSpec

abstract class RemappedViewsSpec @Inject constructor(objects: ObjectFactory)

DSL for a set of remapped dependency views that accept different input namespaces but resolve to one target namespace.

Declare one dependency bucket per input namespace — dependencies are deliberately not classified from coordinates. For example:

remap.remappedViews("mods") {
    targetNamespace.set("named")
    namespace("official", "obfMods") {
        mappingFile.set(officialToNamed)
    }
    namespace("intermediary", "intermediaryMods") {
        mappingFile.set(intermediaryToNamed)
    }
}
