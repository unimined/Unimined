RemapSurfaceSpec

abstract class RemapSurfaceSpec @Inject constructor(val surface: RemapSurface, objects: ObjectFactory) : ExtensionAware

DSL block for one RemapSurface's step pipeline. Steps run in declaration order.

Engine plugins extend the DSL with their own verbs via extension functions — e.g. fun RemapSurfaceSpec.unpick(defs) = step(UnpickSpec(defs)).
