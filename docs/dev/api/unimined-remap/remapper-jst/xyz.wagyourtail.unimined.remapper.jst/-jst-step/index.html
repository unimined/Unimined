class JstStep : RemapStepType<JstStepSpec>

jst step on the SOURCES surface — runs net.neoforged.jst.cli.Main in a JVM subprocess. JST handles jar input/output natively (--in-format ARCHIVE --out-format ARCHIVE), so unlike source-remap no unpack/repack is needed. The step declares needsClasspath — JST resolves symbols against the compile classpath.
