MigrateMappingsTask

@DisableCachingByDefault(because = "migrates + rewrites files in-place — destructive, never cacheable")
abstract class MigrateMappingsTask @Inject constructor(objects: ObjectFactory) : DefaultTask

Migrates a source set's sources onto a different mappings release — the migrateMappings of loom/1.x, redesigned (see plan.md §6):

  • the target is a MappingsSpecImpl configured via target {} (yarn("..."), mcp(...), maven(...), ...), not a second environment,

  • the input environment's full resolved tree and the target tree are grafted through an auto-detected shared namespace (MappingTree.graft) into a direct dev -> target mapping, then UML's SourceRemapper rewrites .java/.kt sources in one pass,

  • non-code files copy verbatim; the result lands in outputDir (loom convention: remappedSrc, outside src/ so it can't become an accidental source root).

Use cases: bumping a named-mappings build (intermediary bridge), dev-ns -> mojmap (official bridge), cross-MC-version where intermediary ids line up between releases.
