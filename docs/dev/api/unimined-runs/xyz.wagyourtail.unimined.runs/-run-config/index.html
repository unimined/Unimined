RunConfig

abstract class RunConfig @Inject constructor(name: String, objects: ObjectFactory, providers: ProviderFactory) : Named

One named run configuration — materialized into a run<Name> task. Un-set fields (main class, args, classpath, natives) default from the environment's launch plan at execution time.

modFolderFiles
Link copied to clipboard
val modFolderFiles: ConfigurableFileCollection

Extra mod jars staged into this run's mod folder by prepare<Name> — loaders whose descriptor declares the modsDir capability copy mod jars into runDir/<dir> (mods/ on forge/conversion-family, plugins/ on bukkit). Files are copied verbatim — never remapped — and are NOT placed on the launch classpath: the loader's own folder discovery is what loads them. Use for jars that must run under the loader's classloader instead of the system one — e.g. a ModLauncher ITransformationService carrier (mixin-engine coremods) whose service-loading/classloader assumptions break on -cp.
