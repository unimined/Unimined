AuthSpec

abstract class AuthSpec @Inject constructor(objects: ObjectFactory)

Per-run auth specification — how the launch's xyz.wagyourtail.unimined.mclauncher.Session is produced. Replaces the 1.x project-global runs.auth: each RunConfig carries its own typed spec, so a client run can log in while a server run stays offline.

Session materialization happens at task-execution time only — no token ever lands on the configuration model or the config cache.

runs.named("client") { auth { microsoft() } }
runs.named("server") { auth { offline("DevServer") } }
runs.configureEach { auth { custom(MyProvider()) } }
