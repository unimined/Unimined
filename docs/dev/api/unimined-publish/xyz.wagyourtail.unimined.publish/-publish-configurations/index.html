PublishConfigurations

object PublishConfigurations

Names of the consumable *Elements configurations the publish wiring creates per bound environment — the producer side of reobfArtifactConfiguration-style in-build consumption.

Dev-channel confs carry the dev-namespace artifacts under custom unimined-dev-* usage values (the unprefixed helpers below); the dev*ElementsName aliases make the channel explicit at the call site. <name>Prod*Elements confs carry the production (reobf-equivalent) jar under the jar's original classifier and the conventional java-api/java-runtime usages. Access-document conf names live on the environment (accessTransformerConfName / accessTransformerElementsConfName).

Prefer attribute-based selection over the configuration = escape hatch: request PublishAttributes.CHANNEL = "prod" (plus ENVIRONMENT/NAMESPACE to disambiguate) on the consumer's resolvable configuration and Gradle picks the matching variant.
