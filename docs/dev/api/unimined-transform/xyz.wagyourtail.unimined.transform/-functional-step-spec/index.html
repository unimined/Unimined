FunctionalStepSpec

class FunctionalStepSpec(val stepId: String, val step: TransformStep, val inputs: Map<String, List<File>> = emptyMap()) : StepSpec

Spec for FunctionalStepType — a declared pipeline step's functional jar-in/jar-out contribution. Built programmatically by the host wiring when bridging xyz.wagyourtail.unimined.transform.step.PipelineStepSpec.transformSteps contributions onto contributeStep — never via the step() DSL, so it needs no objects.newInstance shape.

stepId is the declaring step's StepType.id — it fingerprints the spec for up-to-date checks (the step object itself is serialization-only state).
