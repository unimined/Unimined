PipelineSpec

abstract class PipelineSpec @Inject constructor(val registry: StepTypeRegistry, val objects: ObjectFactory, val presets: PipelinePresetRegistry = PipelinePresetRegistry())

Declared transform-pipeline scope for one environment — the pipeline { } DSL object. Step types register as named extensions (extensions.add("binpatches", spec)): Groovy gets extension dispatch free, Kotlin uses per-type extension fns as shipped sugar.

declaredSteps preserves registration order — extensions.add calls happen in build-script order during evaluation, so the index is captured at add-time and never depends on when configure lambdas later execute (config-cache realization order is intentionally not script order). Steps are singletons per type; repeatable data lives in list fields on the spec.
