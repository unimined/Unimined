probeResolver
Link copied to clipboard
var probeResolver: (String) -> String??

Probe resolver for select(key) pipeline nodes — env wiring (forge's artifact probe picks the era; a declared pin provides ("era" -> "userdev")-style results) installs a resolver that maps probe keys to results. Unresolved keys return null — selecting nothing, so a selector with no null-branch fails at realization per PipelineSpec.SelectorNode.branch.
