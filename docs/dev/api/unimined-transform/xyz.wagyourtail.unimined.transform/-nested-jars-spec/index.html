abstract val fmlModType: Property<String>

Default FMLModType manifest attribute stamped into every embedded jar (MOD/LIBRARY/GAMELIBRARY/LANGPROVIDER/ CUSTOM) — declares each entry's FML layer + scan type without requiring mods.toml inside it. LIBRARY/LANGPROVIDER land in the PLUGIN layer (visible to language providers); MOD/GAMELIBRARY in GAME. Unset embeds untouched — FML defaults nested jars to GAMELIBRARY. jarjar format only.
