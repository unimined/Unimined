object ModDiscoveryFeature : EnvironmentFeature

modDiscovery("classpath"|"dli"|"modClasses"|"plugins") — how the runtime finds dev mods. A custom loader row declaring no discovery binding fails at selection rather than running silently mod-less. plugins stages mod jars into the run dir's plugins/ for native server discovery; classpath uses the CPL java agent.
