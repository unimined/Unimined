BinpatchesPackStepSpec

abstract class BinpatchesPackStepSpec : DevArtifactOnlyStepSpec

forge-binpatch-pack JAR-surface step — FG2-era binary patching: reads binpatches.pack.lzma out of the resolved universal jar (or devbinpatches.pack.lzma out of a FG2 userdev dev package) and applies it with BinpatchesPackPatcher, the in-process GDiff patcher (1.x FG2MinecraftTransformer.transformIntern + FG2TaskApplyBinPatches — no external tool needed, unlike FG3's binpatcher exec).

Passthrough when fields are absent (non-Binpatches profiles).
