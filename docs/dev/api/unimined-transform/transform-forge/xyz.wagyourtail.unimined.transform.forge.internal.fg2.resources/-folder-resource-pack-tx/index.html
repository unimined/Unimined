FolderResourcePackTx

open class FolderResourcePackTx

FMLFolderResourcePack classpath/resource fix — the annotation-driven replacement for what 1.x did as raw ASM (FixFG2ResourceLoading).

Why: FG2-era folder packs only see the mod's own source dir, so resources living under other MOD_CLASSES roots are invisible. The fix records the resolved dirs at construction and teaches hasResource/getInputStreamByName/ getResourceDomains to consult them.

The superclass member names are obf/srg (the universal jar is compiled against obfuscated names) and vary per version, so nothing can be written as a fixed member spec — instead the SUPER_SELF injection target matches same-named super. calls at apply time, and CSuperOverride names the generated delegates after whatever the jar's superclass actually declares.
