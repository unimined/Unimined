GenerateModMetadataTask

@DisableCachingByDefault
abstract class GenerateModMetadataTask : DefaultTask

Emits generated mod metadata + mixin configs for one bound environment into outputDir, which the packaging wiring registers as a resources srcDir. Everything materializes at execution: emitters rediscover via ServiceLoader so no loader objects sit in serialized task state.

Emitted paths that already exist in resourceDirs are MERGED, not rejected: JSON documents deep-merge (objects recurse, arrays union, generated scalars win) and the manual source files are listed in mergedPathsFile so the packaging wiring excludes them from processResources — the merged copy is the only one packaged. Non-JSON collisions still fail.

The task also auto-fills what the mod {} model can't express: hand-written *.mixins.json files in resources are discovered and referenced from loader metadata, classes implementing the emitter's ModMetadataEmitter.gametestInterface become gametest entrypoints, and interfaces implemented by mixin classes are emitted as a transitive-inject-interface classTweaker (declared via the loader's classTweakers metadata key and custom.*injected_interfaces).
