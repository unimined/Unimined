MergeEraJarsTask

@DisableCachingByDefault
abstract class MergeEraJarsTask : DefaultTask

Merges era production artifacts into one distribution jar. This is the shared machinery behind mergedEraJar (single-loader multi-version) and chimeraJar (multi-loader): flattened era entries land in the outer jar, nested era entries are merged first into a generated inner jar at nestedPath, and duplicate jar-relative paths are first-wins.

combineWith output is deliberately prepended as raw source-set output, not as another remapped era artifact: shared code is the merge anchor, so era jars produced with shadow-style composition can have their embedded copies deduplicated away. A future auto-divergence pass (activation stubs / cross-era conflict resolution) belongs here, but is explicitly out of v1 scope — see the JarMerger failure analysis before designing that feature.
