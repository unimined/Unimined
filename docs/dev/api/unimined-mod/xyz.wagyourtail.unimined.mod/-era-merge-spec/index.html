EraMergeSpec

abstract class EraMergeSpec @Inject constructor(objects: ObjectFactory)

DSL model shared by mergedEraJar and chimeraJar.

Era selection defaults to bound, versioned, non-auxiliary environments that still have defaultRemapJar enabled — the product-side equivalent of the fixture-level "include in output" concept. Calling eras replaces that automatic set exactly.
