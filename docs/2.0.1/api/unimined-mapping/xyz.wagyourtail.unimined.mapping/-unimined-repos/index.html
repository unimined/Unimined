UniminedRepos

class UniminedRepos

The full known-repository catalog — every repo the 1.x unimined.*Maven/mcphackersIvy helper verbs registered, as data, plus lookups.

UniminedRepos is a class bound to a RepositoryHandler (or null for the unbound bootstrap instance): constructing an instance registers its catalog entries into the static maps on first touch and exposes each repo pre-bound —

UniminedRepos(project).fabric.ensure()           // project repos
UniminedRepos(settings.dependencyResolutionManagement.repositories)
    .glassLauncher.ensure("babric")              // settings repos

The companion holds the static API: ensureForNotation, the deprecated name-keyed ensure, and the prop-name lookups used by the bound accessors.

val mavenCentral: UniminedRepos.BoundRepo

Maven Central — named MavenRepo so it dedupes against Gradle's own mavenCentral() (settings-mode checks are name-keyed). The excludes mirror 1.x: com.mojang artifacts live authoritatively on Mojang's host, and org.lwjgl must resolve there too — 1.21's natives-macos-patch classifier is absent from central, and Gradle pins a module's artifacts to whichever repo served its metadata. Registering central FIRST keeps its classifiers reachable for modules both hosts carry (netty natives — libraries.minecraft.net serves the POM + main jar but not the linux-x86_64 classifier).
