Perf

object Perf

Cross-module phase timing for the perf megaplan (Docs/perf-plan.md).

Enabled by the unimined.perf Gradle property (mirrored to a system property by syncFrom so Gradle-free core code paths see it), a -Dunimined.perf JVM arg, or the UNIMINED_PERF env var. Events are JSON lines appended to the unimined.perf.file target (default <root>/build/unimined/perf.jsonl when synced from Gradle; UNIMINED_PERF_FILE env or -Dunimined.perf.file wins).

Never fails a build — every public entry point swallows errors.
