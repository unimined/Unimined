PrepareRunTask

@DisableCachingByDefault(because = "run-dir staging is fast and env-local")
abstract class PrepareRunTask : DefaultTask

Stages the run directory before a MinecraftRunTask executes — loader envs contribute staging via prepareTaskMutators (dyn-lib copies, mod-dir seeding, metadata files). Named task so staging is visible in the task graph instead of buried in the run task's doFirst.
