PruneUniminedCacheTask

@DisableCachingByDefault(because = "deletes cache entries — destructive, never cacheable")
abstract class PruneUniminedCacheTask : DefaultTask

Prunes unimined-owned cache directories.

Global root (~/.gradle/caches/unimined, or project .gradle when unimined.useGlobalCache=false) entries whose newest file is older than maxAgeDays are deleted — the mtime window doubles as the "in use by a live daemon" guard. assets/ is skipped by default: it's content-addressed and pruning buys nothing (--assets opts in). --project additionally wipes this project's .gradle/unimined — always safe, it regenerates lazily.

Gradle's own transforms-* cache is GC'd by Gradle and untouched.
