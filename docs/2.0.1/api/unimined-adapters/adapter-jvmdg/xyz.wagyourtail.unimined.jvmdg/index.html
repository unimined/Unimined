DowngradeClassesTask
Link copied to clipboard
@DisableCachingByDefault(because = "jvmdg engine output isn't relocation-verified; up-to-date checks cover the rerun cost")
abstract class DowngradeClassesTask : DefaultTask

Downgrades every directory in inputDirs to classVersion via JvmDowngrader, mirroring each input dir to outputDir/<index> so classpath order is preserved. Registered per-environment by the unimined-jvmdg compat plugin when the env's jvmdowngrader extension is enabled — old-loader runtimes (FG-era LaunchWrapper/FML ship ASM 4/5.2 and cannot read >v52 classes) launch against the downgraded dirs instead of the raw compile outputs.

Per-environment JvmDowngrader settings, contributed by the xyz.wagyourtail.unimined.jvmdg plugin as an extension named jvmdowngrader on each MinecraftEnvironment. On by default — applying the plugin is the opt-in, so every environment downgrades unless enabled.set(false) opts it back out.
