UmlRemapStepType

class UmlRemapStepType : RemapStepType<RemapStepSpec>

The remap step backed by UniminedMappingLibrary's AsmRemapper — binary surfaces (RemapSurface.JAR and the decompile fork RemapSurface.DECOMPILE).

Consumes mappings through the UML MappingTree view typed view, so it gets the full UML tree — including constant-group unpicking (AsmRemapper.Options.unpickConstants) and BytecodeTransform metadata — which a row-only bundle cannot carry.

Classpath entries feed the inheritance pass (AsmRemapper.remap's libraries), so member mappings propagate into subclasses the tree does not list explicitly.
