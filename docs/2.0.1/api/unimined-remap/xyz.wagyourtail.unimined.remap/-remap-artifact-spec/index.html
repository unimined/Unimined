RemapArtifactSpec

abstract class RemapArtifactSpec @Inject constructor(objects: ObjectFactory)

DSL spec for one-off artifact remaps — remap.artifact("name") { }.

Standalone (no Minecraft environment): point input at any jar and mappings at a mapping file in any UML-recognized format (tiny, umf, srg, tsrg, proguard, mcp, ...) or an unimined mapping bundle. When from/to are unset the namespaces are autodetected at execution: the column whose class names best match the input jar becomes the source, and the single remaining column becomes the target.
