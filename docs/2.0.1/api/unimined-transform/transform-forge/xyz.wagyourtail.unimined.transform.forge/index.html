ForgeJsCoremodRemapStepType
Link copied to clipboard
object ForgeJsCoremodRemapStepType : StepType

forge:jsCoremodRemap — rewrite source-namespace names inside coremod .js resources to the target namespace. FG3-era only: JS coremods are the userdev-era ICoreMod script-engine shape (FG1/FG2 coremods are Java classes remapped by the class remapper). Needed for class names under non-mcp dev namespaces (yarn): the csv naming service (1.16.5 MCPNamingService) reads methods/fields csvs only — no class channel — so ASMAPI.mapType/mapClass has nothing to resolve, and literal-embedded names break anyway.

object ForgeSrgRuntimeStepType : StepType

forge:srgRuntime — opt-in FG2 srg-namespace dev launch. A mode step: when declared, the run wiring swaps the launch MC artifact to the mod-source (searge) view and emits -Dunimined.fg2.runtimeDeobf so FML's runtime deobf transformer stays registered — DeobfTweakerTx's strip is inert. Without it (default, 1.x behavior) the dev-mapped jar runs directly.
