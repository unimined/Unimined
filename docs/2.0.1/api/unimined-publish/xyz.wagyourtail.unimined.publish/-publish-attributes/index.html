PublishAttributes

object PublishAttributes

Variant attributes stamped on unimined<Env> component variants so consumers can select dev/prod/sources/data artifacts (plan §11).

Attribute values reflect declared environment metadata only — namespace resolution stays lazy, so NAMESPACE is present only when the env declares devNamespace/modSourceNamespaces explicitly.

  • ENVIRONMENT — environment id (fabric, main, ...)

  • LOADER — loader family name (fabric, forge, ...) when declared

  • NAMESPACE — the artifact's mapping namespace when declared

  • CHANNEL — "dev" or "prod" (absent on data files)

  • ARTIFACT_ROLE — "jar", "sources", "javadoc", or "data"

Dev-channel variants carry a custom org.gradle.api.attributes.Usage value instead of java-api/java-runtime so ordinary consumers resolve the production variants unambiguously; consumers that want a dev artifact request the matching USAGE_DEV_* value explicitly:

dependencies {
    implementation("com.example:mymod-fabric:1.0") {
        attributes {
            attribute(Usage.USAGE_ATTRIBUTE,
                objects.named(Usage::class.java, PublishAttributes.USAGE_DEV_API))
        }
    }
}
