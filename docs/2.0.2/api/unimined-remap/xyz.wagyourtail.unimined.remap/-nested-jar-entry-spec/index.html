FMLModType manifest attribute stamped into the nested jar (MOD/LIBRARY/GAMELIBRARY/LANGPROVIDER/CUSTOM) — declares the jar's FML layer + scan type without requiring mods.toml inside it. LIBRARY/LANGPROVIDER land in the PLUGIN layer (langprovider-visible); MOD/GAMELIBRARY in GAME. Unset embeds as-is — FML defaults nested jars to GAMELIBRARY. jarjar format only; forces the inner rewrite.
