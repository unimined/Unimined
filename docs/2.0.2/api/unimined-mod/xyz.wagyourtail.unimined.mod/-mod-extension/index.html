ModExtension

abstract class ModExtension @Inject constructor(project: Project, objects: ObjectFactory)

The mod { } extension (unimined.mod { } on the frontend) — loader-neutral mod identity plus per-loader sections and generated mixin configs. Loader emitters turn the model into fabric.mod.json, mods.toml, etc. via the ModMetadataEmitterRegistry SPI.

Example:

mod {
    id = "examplemod"
    mixins { create("examplemod") { packageName = "example.mixin" } }
    loader("fabric") {
        entrypoint("main", "example.ExampleMod")
        accessWidener("examplemod.accesswidener")
    }
}
