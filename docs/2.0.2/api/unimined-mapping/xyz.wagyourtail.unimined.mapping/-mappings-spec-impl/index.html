class MappingsSpecImpl(objects: ObjectFactory, mcVersion: Provider<String>? = null, envSide: Provider<Side>? = null) : MappingsSpec

The mappings { } block state: the declared namespace chain plus the ordered list of mapping sources feeding it.

the owning environment's Minecraft version — used by channel sugar such as yarn to default the artifact version; may be null on detached spec instances

fun stubs(vararg namespaces: String, apply: StubsSpec.() -> Unit)

Layer inline patch rows onto this environment's composed mappings (1.x stubs(*namespaces) { }). namespaces binds the row cell order — each c/f/m row's values are positional across it. The rows serialize to a tiny-v2 document at materialization and ride the normal source pipeline, so the merged-mapping cache is content-keyed on the stub bytes (1.x combinedNames -stubs-<sha> parity).
