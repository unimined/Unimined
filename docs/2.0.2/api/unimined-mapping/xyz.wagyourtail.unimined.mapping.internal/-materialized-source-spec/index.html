MaterializedSourceSpec

data class MaterializedSourceSpec(val files: List<String>, val formatHint: String?, val nsMap: Map<String, String>, val namedNamespaces: Set<String>, val attachments: Map<String, String>)

Task-serializable form of a MaterializedMappingSource — declarations (and their mapNamespace/named flags) don't survive being flattened to bare files, so bundle/remap tasks consume this manifest alongside the extracted files and rebuild the materialized sources at execution time. Hand-rolled JSON: the modules consuming this manifest don't all apply the kotlinx.serialization compiler plugin.
