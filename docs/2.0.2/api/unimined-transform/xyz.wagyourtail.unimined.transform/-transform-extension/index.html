TransformExtension

abstract class TransformExtension @Inject constructor(project: Project) : TransformExtensionFacade

The transform { } DSL + pipeline host.

Transforms are declared, not applied — unimined-transform-* plugins (or buildSrc/inline transforms built on the same builder API) register themselves via transformer; cross-cutting decorators via decorator. build wires the declared pipeline provider → transformer(s) → dev artifact entirely through Provider/TaskProvider chains.
