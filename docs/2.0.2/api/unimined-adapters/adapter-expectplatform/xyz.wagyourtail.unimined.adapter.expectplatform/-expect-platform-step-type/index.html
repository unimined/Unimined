ExpectPlatformStepType

class ExpectPlatformStepType : RemapStepType<ExpectPlatformStepSpec>

expectPlatform implementation backed by ExpectPlatform's TransformPlatform: statically resolves the annotation machinery into the jar so prod runs and shipped artifacts need no agent. Environment stripping is deliberately not done here — prod jars stay side-agnostic; loaders read their own (remapped) annotations and strip at runtime.
