JvmDgEnvSpec

abstract class JvmDgEnvSpec

Per-environment JvmDowngrader settings, contributed by the xyz.wagyourtail.unimined.jvmdg plugin as an extension named jvmdowngrader on each MinecraftEnvironment. On by default — applying the plugin is the opt-in, so every environment downgrades unless enabled.set(false) opts it back out.

When enabled, the env's dev run* tasks launch against JvmDowngrader-processed copies of sourceSet.output.classesDirs instead of the raw compile outputs, so loaders whose bundled ASM cannot read modern class files (FG-era LaunchWrapper/FML reads ≤v52; ≤1.6.4-era reads ≤v51) can run modern-compiled mods.

Class-file target as a Java major version (8 → v52, 7 → v51). Conventions to the environment's Minecraft Java floor — the version-json/capability javaVersion (deliberately not MinecraftEnvironment.requiredJavaVersion, which a raised javaVersion inflates: the point of downgrading is to compile newer while emitting bytecode the era runtime can read) — with ≤1.6.4-era versions floored at 7.
